JavaScript DOM Event Object

1. What is the Event Object? (Description)

The Event Object (commonly written as e or event) is a built-in JavaScript object automatically created by the browser whenever an action happens on a web page (such as a button click, key press, text input, or mouse movement).

The browser automatically passes this object as the first argument to your event listener function.

Why do we need it?

  • Identifies the Target: Tells you exactly which HTML element was clicked or modified.
  • Contains User Data: Carries what the user typed, coordinates of the mouse, or which keyboard key was pressed.
  • Controls Flow: Gives methods to cancel default browser behavior (like page reloads) and stop events from bubbling up.

Most Important Properties & Methods

Property / Method Type What It Does
e.target Property The actual element where the event originated (e.g. clicked button).
e.target.value Property The current text typed into an input or textarea.
e.type Property The type of event fired (e.g. "click", "submit", "keydown").
e.key Property The character or name of the keyboard key pressed (e.g. "Enter", "a").
e.preventDefault() Method Stops the browser's default action (e.g., stops forms from reloading the page).
e.stopPropagation() Method Prevents the event from bubbling up to parent containers.
