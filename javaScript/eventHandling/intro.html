JavaScript Event Handling

Learn what events are, 3 ways to handle them, the event object, exhaustive event lists, and usage in React.

1. What is an Event?

An Event is an action, occurrence, or notification generated by the browser or the user. Examples include: clicking a button, typing inside an input box, resizing the browser window, or finishing page load.

Event Handling is writing JavaScript code (called an Event Listener or Event Handler) that "listens" for that event and triggers specific actions in response.

2. Three Ways to Handle Events in JavaScript

Method 1: Inline HTML Attribute (Outdated / Not Recommended)

Written directly in the HTML tag as an attribute (e.g., onclick, onchange). Violates separation of concerns.

<button onclick="alert('Clicked inline!')">Click Me</button>

Method 2: DOM Property Handler (Older JS Method)

Assigned directly to the element object property. Limitation: You can only attach ONE function at a time (reassigning overwrites previous handlers).

const btn = document.querySelector("#myBtn");
btn.onclick = function () {
  console.log("Clicked via DOM property");
};

Method 3: addEventListener() (Modern & Recommended Standard)

The standard and most flexible way. It allows: multiple listeners on the same event, event bubbling/capturing control, and listener removal with removeEventListener. 

const btn = document.querySelector("#myBtn");
btn.addEventListener("click", function (event) {
  console.log("Clicked using addEventListener!", event);
});

3. The Event Object (e or event)

Whenever an event triggers, JavaScript automatically passes an Event Object to the handler callback. It contains detailed information about what happened. 

element.addEventListener("click", (e) => {
  console.log(e.type);            // "click" - type of event
  console.log(e.target);          // The exact element that was clicked
  console.log(e.currentTarget);   // The element the listener is attached to
  
  e.preventDefault();             // Prevents default behavior (e.g. form reload, link navigation)
  e.stopPropagation();            // Stops event bubbling up the DOM tree
});

5. Complete List of Common JavaScript Events

Here are the most frequently used events categorized by their domain:

🖱️ Mouse Events

  • click - Single click on element
  • dblclick - Double click
  • mousedown - Mouse button is pressed down
  • mouseup - Mouse button is released
  • mousemove - Mouse moves over element
  • mouseenter - Mouse enters element (doesn't bubble)
  • mouseleave - Mouse leaves element (doesn't bubble)
  • mouseover - Mouse enters element (bubbles)
  • mouseout - Mouse leaves element (bubbles)
  • contextmenu - Right-click (opens context menu)

⌨️ Keyboard Events

  • keydown - Key is pressed down
  • keyup - Key is released
  • keypress - Key produces character (Deprecated)

📝 Form & Input Events

  • submit - Form is submitted
  • input - Value changes in real-time
  • change - Value committed (loses focus or selected)
  • focus - Element receives focus
  • blur - Element loses focus
  • reset - Form is reset

🌐 Window / Lifecycle Events

  • DOMContentLoaded - HTML & DOM fully loaded
  • load - Entire page (HTML, images, styles) loaded
  • resize - Window size changes
  • scroll - Document or element is scrolled
  • beforeunload - User is about to leave/close tab
  • offline / online - Network connection changes

📋 Clipboard Events

  • copy - User copies text/content
  • cut - User cuts text/content
  • paste - User pastes content

🎯 Drag & Drop Events

  • dragstart - User starts dragging element
  • drag - Element is being dragged
  • dragover - Dragged element is over valid drop target
  • drop - Dragged element is dropped
  • dragend - Drag operation has ended

🎬 Media Events (Audio / Video)

  • play - Audio/video begins to play
  • pause - Audio/video is paused
  • ended - Playback reaches the end
  • volumechange - Volume or mute changed
  • timeupdate - Playback position has changed

📱 Touch Events (Mobile)

  • touchstart - Finger placed on touch surface
  • touchmove - Finger moved across surface
  • touchend - Finger removed from surface
  • touchcancel - Touch interrupted (e.g. alert)

6. How to Use Events in React (JSX)

React handles events similarly to HTML/DOM elements, but with a few crucial syntactic and behavioral differences.

Key Differences: Vanilla JS vs. React

  1. camelCase Naming: React event names are camelCase rather than lowercase (e.g., onClick instead of onclick, onSubmit instead of onsubmit).
  2. Pass Functions, Not Strings: In JSX, you pass the actual function reference inside curly braces {handleClick}, rather than a string "handleClick()".
  3. SyntheticEvent: React wraps browser native events in a cross-browser wrapper called SyntheticEvent. It has the same attributes (e.target, e.preventDefault(), e.stopPropagation()), but ensures consistent behavior across all browsers.
  4. Explicit preventDefault(): You cannot return false to prevent default behavior in React; you must explicitly call e.preventDefault().

Core React Event Patterns

1. Basic Click Handler

function MyButton() {
  function handleClick(e) {
    console.log("Button clicked!", e.target);
  }

  return <button onClick={handleClick}>Click Me</button>;
}

2. Passing Arguments to Handlers (Arrow Function)

function UserList({ users, deleteUser }) {
  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>
          {user.name}
          {/* Use an arrow function wrapper to pass user.id */}
          <button onClick={() => deleteUser(user.id)}>Delete</button>
        </li>
      ))}
    </ul>
  );
}

3. Controlled Input (onChange)

Note: In vanilla JS, change only fires on blur. In React, onChange fires on every keystroke (identical to vanilla input). 

import { useState } from "react";

function SearchBar() {
  const [query, setQuery] = useState("");

  const handleChange = (e) => {
    setQuery(e.target.value); // updates state on every keystroke
  };

  return (
    <input
      type="text"
      value={query}
      onChange={handleChange}
      placeholder="Search..."
    />
  );
}

4. Form Submit with preventDefault()

function LoginForm() {
  const handleSubmit = (e) => {
    e.preventDefault(); // Prevents full page reload
    console.log("Form submitted safely via AJAX / state");
  };

  return (
    <form onSubmit={handleSubmit}>
      <button type="submit">Log In</button>
    </form>
  );
}

5. Keyboard Events (onKeyDown)

function ChatInput({ sendMessage }) {
  const handleKeyDown = (e) => {
    if (e.key === "Enter") {
      sendMessage();
    }
  };

  return <input type="text" onKeyDown={handleKeyDown} />;
}

Event Names: Vanilla JS vs. React Cheat Sheet

Vanilla JS (addEventListener / HTML) React JSX Event Prop Description
click / onclick onClick Mouse click
dblclick / ondblclick onDoubleClick Double click
input / change onChange Fires on every value change
submit / onsubmit onSubmit Form submission
keydown / keyup onKeyDown / onKeyUp Key presses
focus / blur onFocus / onBlur Element gains / loses focus
mouseenter / mouseleave onMouseEnter / onMouseLeave Hover enter / exit
scroll / onscroll onScroll Container scroll
dragstart / drop onDragStart / onDrop Drag-and-drop operations
